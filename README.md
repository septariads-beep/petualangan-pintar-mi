# Petualangan Pintar MI

Game belajar interaktif untuk SD/MI kelas 1–6 (Kurikulum Merdeka) dengan bank soal ASAS 2026/2027.

## Cara main

1. Buka file **index.html** di browser, atau
2. Setelah GitHub Pages diaktifkan, buka link Pages.

## Fitur
- Pilih kelas 1–6
- Banyak mapel MI (Matematika, Bahasa Indonesia, IPAS, PAI, dll.)
- Misi, mini-game, battle kelompok, sertifikat
- Progres tersimpan di perangkat
